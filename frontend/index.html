What problem is this solving?

BB84 decides whether someone is listening by watching a single number: the Quantum Bit Error Rate. If it crosses about 11%, the link aborts.

That rule has a hole in it. An attacker who intercepts only part of the traffic raises the QBER to roughly 5–9% — real leakage, no alarm. And several attacks are worse than silent: detector blinding actually lowers the QBER, because the attacker replaces noisy quantum detection with clean classical pulses.

This project replaces the single-number test with a temporal one: it watches how the error rate behaves over time across 63 physics-derived features, and uses XGBoost to name which of five regimes the link is in. Every alarm carries a SHAP explanation.

◆
The honest headline. The fixed 11% threshold misses 99.4% of attack blocks. The temporal model misses 11.5% — about a nine-fold reduction in false negatives, measured after removing a label-leakage bug that had inflated accuracy to 99.9%.

Why no protocol closes the source side
Every security proof — BB84, decoy-state, MDI, even device-independent QKD — assumes no unwanted light leaves Alice’s and Bob’s laboratories. Trojan-horse and the light-injection family attack that premise from outside the protocol. Only hardware countermeasures plus runtime monitoring help, which is exactly where the ML layer earns its place.

Which family of physics carried the decision?

In plain language

MDI-QKD: making the detectors untrusted

Detector blinding beats BB84 for one structural reason: Eve controls the device that also computes the security check. She fakes the key bits and the monitor meant to catch her.

Measurement-Device-Independent QKD removes that. Alice and Bob both become transmitters; an untrusted relay, Charlie, performs a Bell-state measurement and announces the result publicly. Eve is allowed to be Charlie. She still fails, because the monitor — the X-basis phase error — is computed from states Alice and Bob prepared themselves. She cannot forge what she never saw.

What MDI-QKD does NOT fix
MDI-QKD closes the detector side completely and does nothing for the source side: Trojan-horse probing, laser seeding, induced photorefraction in lithium-niobate modulators, and laser-damage attacks that degrade an isolator to enable the others. Those violate the sealed-laboratory assumption every proof relies on, device-independent QKD included. That is exactly the Phase 3 proposal: keep MDI-QKD as the backbone, and point the temporal ML at source-side telemetry, because those attacks have slow, drifting, inherently temporal signatures.

What changed, and why these numbers deserve more trust than the old ones. The previously reported 99.93% was an artefact. Every class ran at a fixed channel transmittance of 1.0, so transmission_efficiency was exactly 1.000 with zero variance for the Normal and Fractional-IR classes — a perfect giveaway. Each attack also had hard-coded strength constants. Sessions now draw baseline QBER, channel loss, dark counts, detector basis mismatch and attack strength from overlapping ranges, so a benign link can look like a weak attack. Accuracy fell to 85.6%, and that is the number worth reporting.

Which feature families matter?

With the leakage removed, basis-dependent features are the most important group (−7.2%), then channel interaction (−5.4%). Before the fix every group scored under 1%, because one leaked feature carried the whole decision.

A second, milder leak worth knowing about
The stored cross-validation figure (~90.6%) sits above the 86.3% held-out result because that CV shuffles at block level and so splits overlapping windows from one session across folds. The session-level held-out number is the one to quote.

⚠
Limitations. Everything here is simulated — no hardware, no measurement from a physical QKD system. The fake-state, time-shift and PNS models reproduce the qualitative signature of each attack rather than deriving it from a full device model. MDI-QKD key rates are asymptotic, use the infinite-decoy limit, and Y11/e11 are leading-order. Free-space drift is a log-normal AR(1) process on the QBER, not a turbulence model. Phase 3 WS-2 to WS-4 are a specification, not a result.
