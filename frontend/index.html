The Architectural Vulnerability of Static QBER Thresholds

Textbook BB84 decides channel security by checking whether scalar Quantum Bit Error Rate (QBER) crosses the theoretical Shor-Preskill abort limit of 11.0%.

This scalar criterion leaves critical physical vulnerabilities unmonitored. An eavesdropper executing fractional intercept-resend raises QBER to only 5–8%, siphoning cryptographic key material without crossing 11%. Crucially, advanced attacks like detector blinding actually depress QBER below benign baseline levels by substituting quantum Poisson statistics with deterministic classical pulses.

This autonomous security architecture monitors channel dynamics across 63 causal temporal features (windowed error moments, jump energies, basis asymmetries, and yield ratios) to classify quantum channel states into five physical regimes in real time with SHAP interpretability.

Empirical Performance vs Static Baseline. The standard 11% threshold exhibits a 99.4% false negative rate on stealth attacks. The temporal XGBoost model reduces this miss rate to 11.5% — an 8.6× improvement — validated under realistic overlapping nuisance parameters without synthetic label leakage.

Physical Diagnostic Summary

Measurement-Device-Independent QKD (MDI-QKD)

Detector blinding succeeds against BB84 for one structural reason: the eavesdropper controls the hardware that measures the security check. Eve forces classical outcomes on the single-photon detectors.

MDI-QKD removes this structural vulnerability. Alice and Bob act strictly as transmitters; an untrusted relay (Charlie) performs Bell-state measurements. Eve may control Charlie completely, but still cannot breach confidentiality: the security metric (phase error in the X-basis) is computed from random states Alice and Bob prepared themselves.

Subsystems Outside MDI-QKD Scope
MDI-QKD eliminates detector-side vulnerabilities entirely, but leaves source-side vulnerabilities unaddressed: Trojan-horse probe reflections, laser seeding, modulator photorefractive drift, and laser damage to optical isolators. Because these attacks degrade hardware parameters gradually over time, continuous temporal ML telemetry is essential to detect source-side drift.
